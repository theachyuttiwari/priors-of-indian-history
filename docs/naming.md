# Naming: domain candidates and availability

Date checked: 2026-10-15
Working name: **Priors**. Tagline: _What they did before._
Nothing has been registered. This file records live lookups only.

## Method

- `.in` via NIXI RDAP: `https://rdap.nixiregistry.in/rdap/domain/<name>.in`
- `.org` via PIR RDAP: `https://rdap.publicinterestregistry.org/rdap/domain/<name>.org`
- `.com` via Verisign RDAP: `https://rdap.verisign.com/com/v1/domain/<name>.com`
- `.site` via Radix RDAP: `https://rdap.radix.host/rdap/domain/<name>.site`
- `.co` via `whois -h whois.registry.co` (no RDAP server is listed for `.co` in the IANA bootstrap file)
- `rdap.registry.in` does not resolve in DNS. `rdap.org` proxies `.in` correctly but returns 404 for every `.co`, so it was not used for `.co`.
- Controls: a random string returned 404 on each RDAP server and "DOMAIN NOT FOUND" on `.co` whois. `google.co` returned a record.
- Reading: `200` = registered. `404` = not found, so likely available. `FREE` / `REG` for `.co`.
- Collision checks: the WebSearch budget ran out before any brand search ran. The collision column below is from the author's own knowledge and from fetching the live page on each taken domain. Treat it as unverified. Re-run a search on the final 2 or 3 names before you register.

## Notes for the decision

1. The strongest fully-free cluster is Hindi compounds. Every single English or Hindi word is taken on `.in`.
2. Pick `.in` as the primary TLD. It tells readers the subject is India.
3. If you keep "Priors", find out who registered `priors.in` on 2026-08-27 before you build around `thepriors.in`.
4. Run a brand search on the final two names. This file did not do that step; the search budget was exhausted.
5. `.co` was checked by whois, not RDAP. Re-check at the registrar before purchase.
